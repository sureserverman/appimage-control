# Flathub Assets

Place release assets for Flathub submission in this directory.

Required artifacts before submission:

- app icon source/export used for Flathub listing
- 2-4 screenshots of the current UI
- any image assets referenced by metainfo (if hosted/repo-local)

Recommended naming:

- `screenshot-01-main.png`
- `screenshot-02-actions.png`
- `screenshot-03-backup-restore.png`
- `icon-512.png`
